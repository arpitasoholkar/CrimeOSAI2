# SOP: Missing Person Complaint

**SOP ID:** SOP-GEN-004
**Applicable Crime Types:** Missing person (adult/minor), suspected abduction, runaway minor

## 1. Trigger Conditions
Apply this SOP when the complaint mentions:
- A person not reachable/located for a defined period
- Circumstances suggesting the person may be a minor, vulnerable adult, or at risk

## 2. Immediate Actions
1. Record last-seen location, time, clothing description, and a recent photograph.
2. If the missing person is a minor, treat as a suspected kidnapping until located (mandatory FIR, no waiting period).
3. Circulate description to local police stations, railway/bus stations, and check hospitals.

## 3. Investigation Path
1. **Mobile location trace**: Request last known cell-tower location (CDR + tower dump) for the missing person's mobile number from the telecom operator.
2. **Digital footprint**: Check social media activity/last login for the missing person's known accounts (with platform legal request if needed).
3. **CCTV canvas**: Collect CCTV footage from the last-seen location and along probable routes.
4. **Bank/transaction trace**: If the person has used a card/UPI after going missing, request the latest transaction location from the bank.
5. **Public appeal**: Circulate through the Zonal Integrated Police Network (ZIPNET) and missing-persons portal.

## 4. Relevant Legal Sections
- BNS Section 137 (Kidnapping) — if abduction suspected
- BNSS Section 176 (Procedure for investigation)
- Juvenile Justice Act provisions apply in parallel if the missing person is a minor

## 5. Escalation
Escalate to the Anti-Human Trafficking Unit if there is any indication of trafficking, and to senior officers within 24 hours if the missing person is a minor and unlocated.
